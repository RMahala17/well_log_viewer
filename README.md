# Well Log Viewer

A Streamlit-based application for visualizing and analyzing well log data from LAS files.

## Features

- Upload and visualize LAS well log files
- Interactive well log plotting
- View different log curves and depth intervals
- Basic well data exploration
- Simple and user-friendly interface

## Tech Stack

- Python
- Streamlit
- LAS File Processing
- Well Log Visualization Libraries
